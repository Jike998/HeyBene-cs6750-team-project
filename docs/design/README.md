# Design References

This folder holds non-mainline design artifacts and archived concept materials.

## Structure

- `controller_app/`: controller-side concept HTML, handoff notes, screenshots
- `robot_app/`: robot-side concept HTML and screenshots

## Why These Files Live Here

- they are useful for discussion and learning
- they should not clutter the repository root
- they are reference artifacts, not the source of truth for the live Flutter apps

## Mainline Source Of Truth

For implementation work, prefer:

- `apps/control_app`
- `apps/robot_app`
