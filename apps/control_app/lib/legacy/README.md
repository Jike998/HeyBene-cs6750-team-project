# Legacy Code

This folder holds archived scaffolding that is not part of the active `control_app` runtime entry path.

## Current Rule

- active `control_app` work should stay in `lib/app/control_app.dart`, `lib/features/control`, and related shared services
- files under `lib/legacy/` are preserved for reference, comparison, or selective reuse
- do not edit `lib/legacy/` unless you are intentionally cleaning up archive code or extracting something into a shared package
